# RPS Tournament

A Pokemon-style rock-paper-scissors tournament: walk the overworld, beat 15 opponents in a 16-player bracket, climb endless levels, and post your score to the top-10 board. Chiptune music and sound effects, desktop keyboard plus mobile touch controls. No build step, no dependencies.

**Play:** https://jbizzle88.github.io/rps-tournament/

Controls: Arrows/WASD move, Space/Enter talk/confirm, B bracket, M mute, L leaderboard (title). Touch: D-pad, A, B, tap buttons.

Dev: open `index.html`. `python3 build.py` bundles everything into one file at `../rps-tournament.html`.
